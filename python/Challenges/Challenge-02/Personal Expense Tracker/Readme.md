# Challenge 02 — Personal Expense Tracker

A Python-based expense tracking system built using Python fundamentals, loops, conditions, and data structures.

## Project Overview

This project helps users track their daily expenses by storing expense details such as category and amount. It also performs simple financial analysis like total spending, highest expense, lowest expense, and category-wise expense tracking.

The purpose of this challenge is to strengthen Python fundamentals while learning how to use **lists**, **dictionaries**, and **real-world problem-solving logic**.

## Features

- Add multiple expenses
- Store expense records using data structures
- Track spending categories
- Calculate total expenses
- Find highest expense
- Find lowest expense
- Category-wise expense summary
- Budget tracking system
- Spending warning if budget exceeds
