# Contact Manager - Python Challenge

## Objective
Build a simple Contact Manager using Python to practice basic programming concepts and data handling.

## Features
- Add a new contact
- View all contacts
- Search contact by name
- Update contact details
- Delete a contact
- Exit the program

## Concepts Practiced
- Variables
- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- User input handling

## Contact Details
Each contact should store:

- Name
- Phone Number
- Email
- City
## Status: - pending 
## Expected Output
The program should allow the user to manage contacts from a menu-based system.

1. Add Contact
2. View Contacts

4. Update Contact
